# 開始文の雛形

`<>` の部分を置き換えて、エージェントの入力欄に貼る。
開始文を貼っても、実行中のモデルは切り替わらない。後任のエージェントは、ユーザーが自分で起動する。

## 前任へ：通常の準備

```text
foreman-handoff を使って、引き継ぎを準備してください。
後任は <エージェント／モデル> です。今回は準備までにしてください。
引き継ぎ書は <HANDOFF.md などの場所> に置いてください。
完成条件と承認範囲はそのまま維持し、準備が済んだら対象への書き込みを止めてください。
```

## 前任へ：緊急（残りわずか）

```text
foreman-handoff の緊急引き継ぎを実行してください。緊急最小版の5点だけを、<HANDOFF.md> に今すぐ保存してください。
新しい検証は走らせないでください。保存したら書き込みを止め、後任への開始文を示してください。
```

## 後任へ：受け入れて続行

```text
foreman-handoff を使って、<HANDOFF.md> の引き継ぎを受け入れ、作業を続けてください。
前任は対象への書き込みを止めています。まず「未照合」の項目を照らし合わせてください。
通常の作業はご自身でやり遂げてください。委託は <許可しない／許可する範囲> とします。
commit・push などの承認範囲は、引き継ぎ書のとおり維持してください。
```

## 元の主任へ：戻し

```text
foreman-handoff を使って、<HANDOFF.md> を後任として受け入れ直してください。
今の担当 <エージェント> は書き込みを止めています。止めたあとの変更を、現物で照らし合わせてから続けてください。
```
